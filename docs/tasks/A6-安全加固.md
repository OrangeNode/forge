# A6 安全加固

2026-10-09 用户要求按生产环境标准加固测试服务器：后台登录加图形验证码与失败锁定，后台、App 接口与 SSH 换高位端口，排查并修复密码密钥、接口鉴权、上传、限流、安全响应头、数据库缓存暴露、Docker 与防火墙、日志等问题。HTTPS 需要域名或证书，不自行购买或申请。

## 1. 范围与取舍

| 项 | 做法 |
| --- | --- |
| 图形验证码 | 只用于管理员登录：`GET /api/admin/v1/auth/captcha` 返回编号与 PNG data URL，答案只存 Redis，两分钟有效、不区分大小写、无论对错只能用一次。图片由 JDK AWT 绘制（部署镜像自带 DejaVu 字体），不引入新依赖。App 登录不加验证码 |
| 失败锁定 | 原有按账号计数保留（5 次），窗口由 5 分钟改为 15 分钟；新增按来源地址计数（管理员与普通用户分开，15 分钟 20 次，成功不清零）。验证码错误只计来源地址，不计账号，避免他人乱填验证码锁住管理员 |
| 端口 | 已安装的 App（1.0.2 及更早）把 80 端口写死，所以 80 过渡期只保留 App 接口与安装包下载；后台入口 47120、App 入口 39280；SSH 先开 42722 并确认可登录，再关 2222 |
| 入口拆分 | nginx 三个入口各自只转发需要的前缀，后台入口不转发 App 接口，App 入口与 80 不提供后台页面与后台接口，接口文档路径不转发 |
| 限流 | nginx 按来源地址：接口 20 次/秒、登录与注册 10 次/分钟、验证码 30 次/分钟（单独计数）、公开下载 4 个并发；超限返回 HTTP 200 + `body.code=429` |
| 响应头 | 后台页面 CSP（脚本只允许同源；图片、媒体、连接放开 http/https 以显示外链海报和播放外部 m3u8）、`X-Frame-Options: DENY`、`nosniff`、`Referrer-Policy`、`Permissions-Policy`；接口响应头沿用 Spring Security 默认 |
| 容器 | 全部 `no-new-privileges`，后端 `cap_drop: ALL`；数据库、Redis、后端不发布端口（原本即如此） |
| 服务器 | SSH 原本只允许密钥登录；新增 `X11Forwarding no`、`MaxAuthTries 3`、`LoginGraceTime 30`，安装 fail2ban（SSH 10 分钟失败 5 次封 1 小时） |

排查后确认无需修改的项：凭据只在服务器 `.env`（600），不在仓库；接口匿名路径逐条列在 `forge.security.*`，其余一律认证；上传只在后台、按存储方案的扩展名白名单，下载一律 `attachment`；日志不输出口令与令牌，服务器项目日志级别为 INFO；接口文档在部署环境关闭。

## 3. 需要用户决定

- HTTPS：需要域名（解析到本服务器）后申请免费证书。
- 管理员口令最短 5 位是 2026-09-29 按用户要求放宽的，生产环境建议至少 12 位。
- 何时关闭 80 端口（`.env` 设 `LEGACY_HTTP_BIND=127.0.0.1`）：需要确认用户都升级到使用 39280 的版本。
- 是否只允许固定地址访问后台入口。
