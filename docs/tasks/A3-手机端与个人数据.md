# A3-手机端与个人数据

对应 App 计划 T3「手机端与个人数据」。手机界面在 Flutter 仓库 `orange-app`（本地 `E:\project\orange-app`）；本文件记录后端与管理端的改动和验证。2026-10-08 用户因暂时无法测试电视版，要求先做手机版。

## 1. 改动与原因

| 改动 | 原因 |
| --- | --- |
| 观看历史：`member_watch_history`（迁移 `V20261008120000`），`/api/app/v1/member/history` 列表、单部进度、上报、删除、清空 | 断点续播与首页“继续观看”；手机与电视共用同一份云端记录，换设备登录仍能从原位置续播 |
| 收藏：`member_favorite`（同一迁移），`/api/app/v1/member/favorites` 列表、状态、收藏、取消 | 详情页一键收藏，在“我的”里查看 |
| 我的设备：`/api/app/v1/member/devices` 列表与让其他设备下线 | 用户自己查看并管理登录设备；台数上限与超出踢最早登录设备沿用 A1 |
| 意见反馈：`app_feedback`（迁移 `V20261008120100`，含菜单“App 管理 → 反馈处理”），App `POST /api/app/v1/feedback`，后台列表与标记已处理；管理端新增“反馈处理”页 | 播放器内“这集播不了”一键报错（自动带影片、线路、集数）与文字反馈，后台可见并处理 |
| 新配置：`forge.app.feedback-daily-limit` | 常量集中在 `application.yaml` |
| 会话服务新增按原因下线单个设备（自己让设备下线记为 LOGOUT，后台强制下线仍为 ADMIN） | 区分离线原因 |
| App 影片列表按分类筛选时包含该分类的全部可见子分类（`CatalogServiceImpl`） | 手机联调发现：选一级分类“连续剧”时影片都挂在二级分类下，列表为空；电视片库同样受影响 |
| 普通用户改为用户名登录（2026-10-08 用户要求）：迁移 `V20261008150000`（加 `username`、按邮箱前缀回填、删除 `email`）与 `V20261008150100`（反馈快照改为用户名）；删除邮箱验证码、找回密码、发信与 `spring-boot-starter-mail`；注册按来源地址每日限次；管理端会员列表、登录设备与反馈处理显示用户名 | 用户要求“用户名改成字母+数字+下划线，不要邮箱了” |
| 只能登录：公开注册默认关闭（迁移 `V20261008160100`、配置默认值改为 false），后台“会员管理”新增“新建会员”（`POST /api/admin/v1/member/users`，权限 `member:user:create`，迁移 `V20261008160000`），App 只在 `registrationOpen=true` 时显示注册入口，关闭时提示联系客服开通 | 用户要求“不开启注册，只能登录”“app 根据后台开关启动注册，关闭注册” |

取舍：

- 影片只保存逻辑 ID，不建跨模块外键；列表经影片目录端口按页批量读取，下架影片被跳过，因此某页条数可能少于每页条数，总数按库内记录计算。
- 扫码登录：用户 2026-10-08 要求暂不做，手机与电视都用邮箱账号密码登录；已写的扫码接口与界面已删除，不保留半成品。
- 反馈“一键跳到对应影片停用线路”本次未做，后台页面显示影片、线路与集数，处理人在视频管理中操作后标记已处理。
- 会员中心只展示 VIP 状态与到期时间，兑换码与套餐属于 T4。
