# A4-广告与版本更新

2026-10-08 用户要求：开屏广告、首页轮播图或广告、观看记录只显示最新 10 个、logo 改为橙色橘子加绿叶、后台可配置版本更新并强制更新（文件管理产生 APK 外链）。手机与电视共用一个 APK（按设备自动切换界面），版本配置只有一套。App 界面在 `orange-app` 仓库；本文件记录后端、管理端与联调结果。

## 1. 改动与原因

| 改动 | 原因 |
| --- | --- |
| 观看记录每人只保留最近 `forge.member.history-keep`（默认 10）条：上报进度后删除更早的记录，列表固定返回最近 10 条；App 首页“继续观看”与观看历史同样最多 10 条 | 用户要求“观看记录只显示最新 10 个” |
| 开屏增加点击跳转（`target_type` NONE/VIDEO/URL、`target_value`），轮播增加 `URL` 跳转类型与 `target_url`（迁移 `V20261008170000`）；外部链接只接受带主机名的 http/https；管理端开屏与轮播表单增加跳转选择 | 开屏广告、首页轮播广告，手机与电视都显示 |
| 文件公开外链：`file_record.public_token`（迁移 `V20261008165000`，权限 `file:record:share`）；`POST/DELETE /api/admin/v1/files/{id}/public-link` 生成或撤销；`GET /api/public/v1/files/{令牌}/{文件名}` 匿名下载，支持单段 Range 断点续传（206 / 416）；管理端文件列表显示并可复制外链 | 用户要求文件管理产生 APK 外链 |
| 上传上限改为 200MB（请求 210MB），nginx `client_max_body_size 210m` | 容纳 APK（当前约 93MB） |
| 版本更新：`app_release` 单行（同一迁移，菜单“App 管理 → 版本更新”，权限 `app:release:view/edit`）；发布时读取已上传 APK，解析包名、versionCode、versionName 并计算 SHA-256，包名必须等于 `forge.app.package-name`、版本号必须高于当前版本，否则 400；勾选强制更新时最低可用版本等于新版本；可调整最低可用版本、撤销发布；启动配置 `launch.release` 下发版本、最低可用版本、外链、SHA-256 与大小 | 用户要求“有新版本必须强制更新”；协调方补充自动解析、最低版本与校验 |
| App：低于最低可用版本时停在更新页（返回键无效），介于两者之间可“以后再说”；断点续传下载、显示进度、已下载且校验通过直接安装、校验不一致删除重下；未允许“安装未知应用”时引导去设置页；失败或设备禁止安装时显示二维码供手机扫码下载（界面不显示服务器地址） | 同上 |
| App 正式签名：钥匙与签名配置放在仓库外，release 构建缺少签名配置直接失败 | 覆盖安装必须同一把钥匙 |
| logo：橙子加绿叶，App 图标（传统 + 自适应）、电视横幅、启动窗口、开屏/登录/更新页 logo；管理端 favicon、侧栏与登录页 logo | 用户要求 |

取舍：

- APK 解析自行实现（只读 `AndroidManifest.xml` 二进制 XML 的 manifest 元素），不引入长期未维护的第三方解析库；只顺序读一遍文件同时计算摘要。
- 版本号不能回退：要回到旧版本只能“撤销发布”后重新发布，或打更高版本号的包。
- 外链只凭随机令牌访问，撤销立即失效；撤销当前安装包的外链会让 App 无法下载更新，页面有提示。

## 轮播图按模板生成（2026-10-09）

用户要求：后台新增轮播时选择影片，按测试服务器上已配置的轮播样式自动生成图片。

| 项 | 实现 |
| --- | --- |
| 后端 | `GET /api/admin/v1/video/videos/{id}/poster`（权限 `video:video:view`）：服务端按影片当前海报地址代取图片后原样返回。海报站不允许跨域，浏览器直接取图会污染画布、无法导出，所以由后端同源返回。地址校验与采集共用（拒绝内网、本机、带凭据和非 HTTP 地址），不跟随重定向；只接受 JPEG、PNG、WebP、GIF（SVG 可带脚本，不放行）；大小上限 `forge.video.max-poster-bytes`（默认 5MB）；不缓存、不落盘。影片不存在 404，没有海报 400，海报站不可用 503 |
| 前端 | “App 管理 → 首页轮播”的新增或编辑表单中，跳转目标选“影片”并选定影片后出现“按模板生成图片”：可填宣传语（留空取简介第一句），点“生成图片”后用浏览器画布绘制 1280×600 的图片（模糊海报背景、右侧清晰海报、左侧“热播推荐”角标、片名、宣传语、分类与年份、“立即观看”），经文件管理上传并自动填入图片；标题为空时同时填入片名。模板在 `frontend/admin/src/views/app/banner-template.ts` |
