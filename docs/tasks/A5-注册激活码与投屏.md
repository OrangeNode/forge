# A5-注册激活码与投屏

2026-10-09 用户要求：注册需要激活码、手机播放可投屏到电视、长按视频倍速播放；完成后升级 1.0.2 并在测试服务器发布为强制更新。App 界面在 `orange-app` 仓库；本文件记录后端、管理端、发布与联调结果。

## 1. 改动与原因

| 改动 | 原因 |
| --- | --- |
| 新表 `member_activation_code`（迁移 `V20261009090000`）与菜单“会员管理 → 激活码”（`V20261009090100`，权限 `member:activation:view/create/revoke`） | 激活码作为注册专用的码，与 VIP 分开 |
| 注册接口增加必填 `activationCode`：校验存在、未使用、未作废、未过期；建号后用“仍未使用且未过期”的条件更新核销，并发抢同一码时后到者 409 且账号回滚 | 每个码只能注册一次 |
| 同一来源地址每天输错激活码达 `forge.member.activation.ip-daily-fail-limit`（默认 20）次后当天拒绝（429） | 防止穷举 |
| 管理端“激活码”页：按激活码/使用账号、备注、状态筛选；批量生成（数量、有效期、备注）后弹窗展示并可一键复制；复制单个码；作废未使用的码；列表显示使用账号与使用时间 | 管理与追踪谁用了哪个码 |
| App：注册页增加激活码；手机播放器长按临时 2 倍速、松手恢复；右上角投屏按钮用 DLNA 搜索同一 Wi-Fi 下的电视/盒子并投放当前分集 | 用户要求 |

取舍：

- 开放注册时激活码一律必填，不再另设“是否需要激活码”开关；不想让人注册时关闭注册开关即可。
- 激活码只存规范化的大写字符，过期不写状态，由有效期推算；已过期但未使用的码仍可作废。
- 投屏只把视频地址交给电视，由电视自己拉流；电视端 App 没有加投屏接收（盒子自带的 DLNA 接收即可）。
