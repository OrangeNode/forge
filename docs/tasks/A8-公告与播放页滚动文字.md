# A8-公告与播放页滚动文字

2026-10-09 用户要求：App 管理新增公告，进入首页弹窗，可选“知道了”或“去了解”，内容可用 HTML 自定义；视频播放页线路上方显示后台配置的滚动文字，可选颜色，先配置为“请勿相信视频中任何广告，视频中广告均为诈骗”。App 界面在 `orange-app` 仓库，本文件记录后端、管理端、App 与发布结果。

## 1. 改动

| 项 | 实现 |
| --- | --- |
| 数据 | 迁移 `V20261009190000`：`app_announcement`（标题、TEXT/HTML 内容、内容版本 `revision`、按钮 NONE/VIDEO/URL、生效时间、启用、优先级、逻辑删除）；`app_announcement_read`（用户 + 公告联合主键，记录看过的版本）；`app_settings` 增加 `marquee_enabled`、`marquee_text`、`marquee_color` 并初始化为启用、上述文字、`#FF3B30`；菜单“App 管理 → 公告管理”（`app:announcement:view/edit/delete`）与“播放页滚动文字”（`app:marquee:view/edit`） |
| 后台接口 | `GET/POST /api/admin/v1/app/announcements`、`PUT/DELETE /api/admin/v1/app/announcements/{id}`；`GET/PUT /api/admin/v1/app/marquee`（启用时文字不能为空，颜色 `#RRGGBB`） |
| HTML 过滤 | 后端保存前用 jsoup 1.23.2 按白名单过滤（p、br、div、span、b、strong、i、em、u、s、del、small、h1—h4、ul、ol、li、blockquote、hr、a[href]、img[src,alt,width,height]、font[color]；链接与图片只留 http(s) 与站内相对地址），过滤后为空返回 400。App 端自写渲染器只认同一白名单，script、style 等整段丢弃，未知标签只显示文字 |
| 弹出规则 | `GET /api/app/v1/app/announcement`（需登录）返回生效中、当前用户没看过当前版本的公告里优先级最高的一条（数字小优先，同优先级新建的优先）；关闭后 `POST /api/app/v1/app/announcement/{id}/read` 记录版本。修改标题、内容或按钮时版本加一会再弹一次；只改时间、开关、优先级不再弹。已读记在服务端，同一用户手机和电视只弹一次 |
| 滚动文字 | `GET /api/app/v1/app/player-marquee`（需登录），未启用时为空 |
| 管理端 | “公告管理”列表与表单（纯文本/HTML 切换、沙箱框架预览、按钮选择影片或链接、生效时间）；“播放页滚动文字”页（开关、文字、取色器与红橙黄白色板、深色底滚动预览） |
| App | 首页数据加载后检查公告：手机为对话框，“去了解”跳影片详情或用浏览器打开链接，正文中的链接可点；电视为遥控器对话框（左右切按钮、上下滚动正文、返回键等同“知道了”），设备没有浏览器时链接类公告不显示“去了解”。播放页：手机在竖屏线路面板和横屏选集侧栏的“线路”上方，电视在播放信息层“线路：”上方和选集面板“线路”上方，循环从右向左滚动 |

取舍：

- “多条只弹一条”取用户还没看过的第一条，而不是固定只看最高优先级那条，避免高优先级公告看过后低优先级的永远弹不出来。
- 已读存服务端而非本机，满足“每个用户只弹一次”，换设备不重复弹。
- HTML 不允许 style 属性，颜色只通过 font color，避免引入 CSS 解析。
