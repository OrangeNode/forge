# A2-电视端后端配合

对应 App 计划 T2「电视端可看」。T2 的主体在 Flutter 仓库 `orange-app`（本地 `E:\project\orange-app`）；本文件只记录为电视端必须做的后端改动与验证。

## 1. 改动与原因

| 改动 | 原因 |
| --- | --- |
| 影片拼音首字母搜索：`video_video.name_initials`（迁移 `V20261008090000`）、`PinyinInitials` 计算、新采集与编辑同步写入、启动后分批回填历史影片 | 电视只能用遥控器在屏幕字母键盘上输入；中文片名只能靠拼音首字母检索（如 `qyn` → 《庆余年》）。原接口只支持片名包含匹配，电视端无法搜到中文片名 |
| `/api/app/v1/video/videos` 的 `keyword`：只由 1—32 个字母数字组成时，同时按首字母前缀匹配；中文关键字仍按片名包含匹配 | 兼容原有搜索，不改变接口字段 |
| 新依赖 `com.ibm.icu:icu4j` 78.3（只在 `forge-video`） | 常用字按 JDK 中文排序规则取首字母（多音字“长”取 c，贴近片名常用读音）；排序规则覆盖不到的生僻字（“飙”“琊”“饕餮”等）由 ICU 汉字转拼音补全。见[技术选型与版本](../技术选型与版本.md) |

取舍：多音字（如“重生”“了不起”）无法保证与用户输入一致，片名包含匹配仍然保留；首字母只做前缀匹配，避免短输入命中大量无关影片。
