# 后台使用教程

后台地址：`http://admin.orangenode.cn/`（测试服务器；也可用 `http://103.242.13.62:47120/`）。本文按“第一次上线要做什么”和“各菜单怎么用”两部分写。每个页面的字段旁都有说明，这里只讲用途和顺序。

## 1. 登录与账号

- 登录需要用户名、口令和图形验证码（看不清点图片换一张，两分钟内有效）。
- 同一账号连续输错 5 次锁定 15 分钟；同一网络地址 15 分钟内失败 20 次也会被拒绝。
- 初始管理员是 `admin`，口令在服务器 `/opt/orange-forge/.env` 的 `FORGE_INIT_ADMIN_PASSWORD`。第一次登录后在“系统管理 → 用户管理”对 admin 点“重置密码”换成自己的口令。
- 左侧菜单可折叠；打开的页面在顶部形成标签，可来回切换。看不到某个菜单说明当前账号的角色没有授权（见第 3.6 节）。

## 2. 第一次上线的顺序

| 步骤 | 菜单 | 做什么 |
| --- | --- | --- |
| 1 | 文件与存储 → 存储配置 | 确认有一个“默认”存储方案（测试服务器用“本地存储”）。图片、安装包都存在这里 |
| 2 | 视频管理 → 资源站管理 | 确认资源站启用；每个站点“分类映射”，点“一键创建缺少分类并绑定” |
| 3 | 视频管理 → 资源站管理 / 资源搜索 | 先小范围手动采集（范围选“当日”），在“采集记录”看结果 |
| 4 | 视频管理 → 采集任务 | 新建定时任务（例如每小时采一次当日更新），检查后启用 |
| 5 | App 管理 → 首页与开屏 | 配置开屏、首页轮播、首页推荐位、热搜 |
| 6 | App 管理 → 功能与版本 | 设置 VIP 开关、是否开放注册、同时登录台数；上传发布 App 安装包 |
| 7 | 会员管理 | 生成激活码或直接新建会员、开通 VIP |

## 3. 各菜单

### 3.1 工作台

系统概览与最近动态，只用于查看。

### 3.2 视频管理

| 页面 | 用途 |
| --- | --- |
| 资源站管理 | 采集来源（预置量子、非凡、光速、红牛）。可启停、改地址；“分类映射”把资源站的分类对应到本库分类：“自动识别并绑定”按名称匹配已有分类，“一键创建缺少分类并绑定”会顺便新建本库没有的分类。已手工绑定的不会被覆盖。每行“搜索”按钮直接搜该站 |
| 视频分类 | 本库分类树（App 里看到的就是它）。停用分类后其下影片在 App 中隐藏 |
| 视频管理 | 已入库影片：编辑资料、上架/下架、删除；线路可启停与排序。人工编辑过的资料会被锁定，之后采集不再覆盖资料（播放地址仍会更新） |
| 视频采集设置 | 去重规则、缺失信息怎么处理（待确认/跳过/允许为空）、最大并发采集数等。不确定时保持默认 |
| 采集任务 | 定时采集。执行时间用五段 cron（分 时 日 月 周，北京时间），例如 `0 * * * *` 每小时整点、`30 3 * * *` 每天 3:30。范围：当日（24 小时内更新的）、本周（168 小时）、全部。新任务默认停用，检查好映射后再启用 |
| 采集记录 | 每次采集的进度、处理数、入库数、失败原因；可停止、继续、重新采集、删除。“待确认”列表是没法自动判断的影片（缺资料、多部同名候选、源站数据格式异常），可以逐条绑定到已有影片、新建或忽略，也可批量“按最新规则采集” |
| 资源搜索 | 按片名搜资源站（全部启用的站或单个站），结果显示“本站已采集 / 库里有同名 / 未入库”，勾选后“采集勾选”或“本页全部采集” |

采集是从资源站拉取影片资料和播放地址，不下载视频本身。

### 3.3 会员管理（App 用户）

| 页面 | 用途 |
| --- | --- |
| 用户列表 | App 普通用户。可“新建会员”（关闭公开注册时用这个开账号，可同时开通 VIP）、开通或延长 VIP、重置密码、停用（停用后该用户所有设备立即下线） |
| 登录设备 | 用户登录过的设备，可强制下线。每个账号最多同时登录几台在“功能开关”里设置 |
| 激活码 | 注册用的激活码，一码只能注册一个账号。生成时选会员时长（1 个月、3 个月、半年、一年或自定义天数），时长从用户注册成功开始算；老用户也可以在 App 里用激活码续费。支持勾选后批量作废、批量删除（已使用的码保留）、导出 CSV 发给代理或客户 |

### 3.4 App 管理

**首页与开屏**（四个标签）：

| 标签 | 用途 |
| --- | --- |
| 开屏设置 | App 启动时显示的图片。手机封面图（竖版 1080×1920）必传，电视封面图（横版 1920×1080）可不传；可设停留秒数、是否可跳过、上下线时间、点击跳转（影片或外部链接） |
| 首页轮播 | 首页顶部轮播。跳转目标选“影片”后可以“按模板生成图片”，自动用影片海报生成 1280×600 的轮播图；也可单独上传电视图 |
| 首页推荐位 | 首页的推荐行，例如“最新电影”。数据来源可选某个分类（自动按更新时间取最新）或手动挑选影片 |
| 热搜设置 | 搜索页的热搜词：手动热搜词与屏蔽词 |

**公告与提示**（两个标签）：

| 标签 | 用途 |
| --- | --- |
| 公告管理 | App 首页弹窗公告。内容可以是纯文字或 HTML（有样例模板可选，右侧预览）；按钮“知道了”始终显示，可再加“去了解”跳到影片或外部链接；“弹出频率”可选只弹一次、每天一次、每次进入 App；多条公告按优先级（数字小优先）每次只弹一条。改了标题、内容或按钮会对已看过的用户再弹一次 |
| 播放页滚动文字 | 播放页线路上方循环滚动的一行字，可设开关、文字和颜色 |

**功能与版本**（两个标签）：

| 标签 | 用途 |
| --- | --- |
| 功能开关 | VIP 开关（开：只有 VIP 能看；关：登录即可看）、开放注册（关闭时 App 只显示“联系客服开通”）、同一账号同时登录台数、客服文字 |
| 版本更新 | 上传 APK 发布新版本，自动识别包名与版本号；“强制更新”勾选后旧版本必须更新。详细步骤见 orange-app 仓库《APK 打包签名与发布教程》，版本号规则见其《版本号说明》 |

**反馈处理**：App 里用户提交的意见反馈和“这集播不了”报错。处理后标记“已处理”并填写备注。

### 3.5 文件与存储

| 页面 | 用途 |
| --- | --- |
| 文件列表 | 所有上传的文件（开屏图、轮播图、安装包等）。可下载、复制公开外链。**正在使用的安装包外链不要撤销**，否则 App 无法下载更新 |
| 存储配置 | 存储方案（本地或 S3/MinIO 兼容的对象存储）。新方案先“检测连接”再“设为默认”；切换默认后旧文件仍能从原方案读取 |

### 3.6 系统管理

| 页面 | 用途 |
| --- | --- |
| 用户管理 | 后台管理员账号：新建、启停、重置密码、分配角色 |
| 角色管理 | 角色及其可见菜单和可用操作。例如给运营人员建一个只能管理 App 首页和公告的角色 |
| 菜单与权限 | 菜单树与每个菜单的权限标识。一般不需要改，新增功能时由版本更新自动写入 |

### 3.7 审计中心

| 页面 | 用途 |
| --- | --- |
| 操作日志 | 谁在什么时候做了什么操作、结果如何 |
| 登录日志 | 后台登录成功与失败记录，可用来发现有人在猜口令 |

## 4. 常见问题

| 问题 | 处理 |
| --- | --- |
| App 里看不到刚采集的影片 | 检查影片是否上架、所在分类及上级分类是否启用；“采集记录 → 待确认”里的影片还没入库 |
| 用户说“开通 VIP 后才能观看” | 在“用户列表”给该用户开通 VIP，或在“功能开关”关闭 VIP 开关 |
| 用户注册提示激活码不正确 | 激活码已被使用、已作废，或输入有误；在“激活码”页按码查询状态 |
| 用户说登录后把别的设备挤下线 | 超过“同时登录台数”时最早的设备会下线，可在“功能开关”调大 |
| 发布新版本提示版本号不高于当前版本 | 打包前没有提高 versionCode，见 orange-app《版本号说明》 |
| 公告不弹 | 检查启用、生效时间、弹出频率；“只弹一次”的公告用户看过后不会再弹，修改内容可让它再弹一次 |
