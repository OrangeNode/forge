# 常用命令

本机（Windows）手动启动、编译与部署的速查表，以 PowerShell 为主。详细说明见[本地开发指南](本地开发指南.md)与[部署指南](部署指南.md)，App 部分见 orange-app 仓库 README。

标注说明：“已验证”表示 2026-10-08 在本机实际执行过；“未实际执行”表示命令按项目配置整理，本次没有运行。本文不含任何密码或密钥内容。

## 2. 本机后端（orange-forge）

### 2.1 依赖服务：MySQL 与 Redis（Docker Desktop）

~~~powershell
cd E:\project\orange-forge
docker compose --env-file .env.local -f docker/compose.yaml up -d --wait   # 启动（已验证）
docker compose --env-file .env.local -f docker/compose.yaml ps             # 状态（已验证）
docker compose --env-file .env.local -f docker/compose.yaml stop           # 停止，数据保留
~~~

凭据在根目录 `.env.local`（不进仓库）；`application.yaml` 的本机默认值已与之对应，后端无需额外设置。

### 2.2 启动 Java 后端（端口 8080）

开发方式（未实际执行）：

~~~powershell
cd E:\project\orange-forge\backend
.\mvnw.cmd -B -pl forge-application -am spring-boot:run
~~~

打包 jar 运行（已验证）：

~~~powershell
cd E:\project\orange-forge\backend
.\mvnw.cmd -B package -DskipTests
java -jar forge-application\target\forge-application-1.0.0.jar
~~~

Ctrl+C 停止。本机初始管理员为 `application.yaml` 中的默认演示账号（只用于本机）。

### 2.3 后端测试

~~~powershell
cd E:\project\orange-forge\backend
.\mvnw.cmd -B clean verify                    # 全量：编译、测试、Checkstyle、注释与模块规则（已验证）

~~~

全量检查前先停掉正在运行的后端，避免 jar 被占用。

## 4. App（orange-app）

### 4.1 检查与编译

接口地址由 `config\` 下的环境文件决定，App 界面不显示也不能修改：`config\dev.json` 指向模拟器访问的本机后端 `http://10.0.2.2:8080`，`config\test.json` 指向测试服务器 `http://103.242.13.62`。

~~~powershell
cd E:\project\orange-app
flutter pub get
flutter analyze                                                        # 已验证
flutter test --dart-define-from-file=config/dev.json                   # 已验证
flutter build apk --release --dart-define-from-file=config/test.json   # 测试服务器包（已验证）
flutter build apk --debug --dart-define-from-file=config/dev.json      # 本机联调包
~~~

APK 输出在 `E:\project\orange-app\build\app\outputs\flutter-apk\`（`app-release.apk`、`app-debug.apk`）。release 构建不带配置文件会直接失败。

### 4.2 电视模拟器

~~~powershell
# 启动前清掉代理变量，否则模拟器访问不到 10.0.2.2
Remove-Item Env:HTTP_PROXY,Env:HTTPS_PROXY,Env:http_proxy,Env:https_proxy -ErrorAction SilentlyContinue
emulator -list-avds                          # 已验证
emulator -avd orange_tv_1080p -gpu host      # 已验证
adb devices
~~~

模拟器上视频画面为黑屏（media_kit 在模拟器只能软件渲染），播放进度与逻辑正常，画面需在真机确认。

### 4.3 安装与运行

~~~powershell
# 装到模拟器并启动（已验证）
adb install -r E:\project\orange-app\build\app\outputs\flutter-apk\app-release.apk
adb shell monkey -p cn.orangenode.orange_app -c android.intent.category.LEANBACK_LAUNCHER 1
adb shell pm clear cn.orangenode.orange_app    # 清除 App 数据（已验证）
adb emu kill                                   # 关闭模拟器（已验证）

# 连着模拟器运行调试版，可热重载（未实际执行）
~~~

## 5. 测试服务器 103.242.13.62

### 5.1 登录与日常操作

~~~powershell
ssh -i $env:USERPROFILE\.ssh\orange_deploy_ed25519 -p 2222 root@103.242.13.62   # 已验证
~~~

服务器上（已验证查看状态与查口令的命令；重启类命令未在本文整理时执行）：

~~~bash
cd /opt/orange-forge
docker compose ps                        # 四个容器状态
docker compose logs -f backend           # 后端日志，Ctrl+C 退出
docker compose logs --tail 200 web       # nginx 日志
docker compose restart backend           # 只重启后端
docker compose stop                      # 停止全部，数据保留
docker compose up -d                     # 启动全部
grep FORGE_INIT_ADMIN_PASSWORD .env      # 查看初始管理员口令（只在服务器 .env 中）
~~~

禁止执行 `docker compose down -v`，会删除数据库、Redis 与上传文件的数据卷。访问地址：管理端 `http://103.242.13.62/`，App 接口 `http://103.242.13.62`。

### 5.2 更新后端与管理端

在本机构建后上传，服务器上重建两个应用镜像（2026-10-08 首次部署按此流程执行）：

~~~powershell
cd E:\project\orange-forge
cd backend; .\mvnw.cmd -B package -DskipTests; cd ..
cd frontend\admin; pnpm run build; cd ..\..

$key = "$env:USERPROFILE\.ssh\orange_deploy_ed25519"
scp -i $key -P 2222 backend\forge-application\target\forge-application-1.0.0.jar root@103.242.13.62:/opt/orange-forge/backend/app.jar
ssh -i $key -p 2222 root@103.242.13.62 "rm -rf /opt/orange-forge/web/dist"
scp -i $key -P 2222 -r frontend\admin\dist root@103.242.13.62:/opt/orange-forge/web/
ssh -i $key -p 2222 root@103.242.13.62 "cd /opt/orange-forge && docker compose up -d --build backend web && docker compose ps"
~~~

修改了 `deploy/compose.yaml`、`deploy/web/nginx.conf` 或 Dockerfile 时，把对应文件一起上传到 `/opt/orange-forge` 下的同名位置再执行最后一步。

### 5.3 基础镜像（服务器无法访问 Docker Hub）

只有更换基础镜像版本时才需要。在本机拉取、打包后上传导入：

~~~powershell
docker pull --platform linux/amd64 mysql:8.4.11
docker pull --platform linux/amd64 redis:8.10.1-alpine
docker pull --platform linux/amd64 eclipse-temurin:21.0.8_9-jre-noble
docker pull --platform linux/amd64 nginx:1.28.0-alpine
~~~

~~~bash
# Git Bash：打包并上传
docker save mysql:8.4.11 redis:8.10.1-alpine eclipse-temurin:21.0.8_9-jre-noble nginx:1.28.0-alpine | gzip -1 > /e/dev/tmp/of-base-images.tar.gz
scp -i ~/.ssh/orange_deploy_ed25519 -P 2222 /e/dev/tmp/of-base-images.tar.gz root@103.242.13.62:/root/orange-upload/
# 服务器上导入
gunzip -c /root/orange-upload/of-base-images.tar.gz | docker load
~~~

导入后删除本机和服务器上的压缩包。
