# forge

Orange Forge：基于 Java 21、Spring Boot、Vue 3 与 TypeScript 的可复用脚手架，包含模块化单体后端与单个后台管理前端。

- [文档索引](docs/文档索引.md)
- [本地开发指南](docs/本地开发指南.md)
- [里程碑与进度](docs/里程碑与进度.md)

当前 M0—M5 已完成，M6 尚未开始；具体能力与验证范围以项目文档为准。
2026-09-29 结构调整：前端由双端收敛为单一后台管理前端，身份由管理员/普通用户双身份收敛为单一管理员身份，详见[架构设计](docs/架构设计.md)第 8 节变更记录。
2026-09-29 M3：管理员认证（登录、退出、身份、菜单）、Redis 令牌会话与撤销、RBAC 权限注解、安全过滤链收紧、初始管理员引导与登录页骨架已落地。
2026-09-29 M4/M5：文件与存储（本地 + S3、配置版本化、上传下载、AES-GCM 凭据加密）、审计（操作审计注解、登录/操作日志与查询）、系统管理接口（管理员/角色/菜单/权限与版本化权限缓存）与按「克制科技 · Calm Tech」实现的管理端页面（工作台、系统管理、文件与存储、审计中心）已落地，并在真实 MySQL 8.4、Redis 与 MinIO 上完成验证。
